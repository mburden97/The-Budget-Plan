OFX or QFX ("Quicken" / "Money" format) is the best choice when it's offered: its columns are standard and each transaction carries the bank's own id, so nothing needs mapping and re-imports are exact. The file is read into memory only. It is never saved to disk, and only the transactions end up in your encrypted vault.
